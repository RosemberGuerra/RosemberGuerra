# Rosember Guerra-Urzola

I operate at the intersection of computational science and software engineering — translating advanced statistical, optimization, and machine learning methods into robust, sustainable, and reproducible tools that hold up outside of a paper.

Most of my current work centers on high-dimensional multi-omics and biomedical data, with a primary mission: building modular software packages, automated workflows, and accessible interfaces that turn complex mathematical theory into practical research tools.

### Featured Research Software

#### 🚀 [Gene Prioritization Explorer](https://gene-prioritization.streamlit.app/)
An interactive web application built with Streamlit allowing Neurologist and pharmacologists to explore, filter, and prioritize multi-omics targets interactively without writing code.

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://gene-prioritization.streamlit.app/)

#### 📦 [mbpls-em](https://github.com/RosemberGuerra/mbpls-em)
Probabilistic multi-block Partial Least Squares (MB-PLS) with EM estimation for integrating heterogeneous multi-omics data across sample cohorts. Developed within the EU SynOD consortium.
